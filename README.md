# Автоматизация SQL и API

Проект содержит решение второй части практического блока: SQL-запросы и API-тест получения заказа по трек-номеру.

## SQL

Готовые запросы находятся в [Request.sql](Request.sql):

1. логины курьеров и число их заказов со статусом «В доставке»;
2. трекеры заказов и вычисленный статус заказа.

## API-тест

## Файлы проекта

- `configuration.py` — адрес тестового стенда и пути API;
- `data.py` — тестовые данные для запросов;
- `sender_stand_request.py` — функции отправки запросов к API;
- `create_order_test.py` — тесты по созданию заказа и получнию заказа по трек номеру;
- `.gitignore` — исключения для Git.
- `autotest.png` — скриншот с запуском теста в VS.

1. создаёт заказ через `POST /api/v1/orders`;
2. сохраняет поле `track` из ответа;
3. получает заказ через `GET /api/v1/orders/track?t={track}`;
4. проверяет HTTP-код `200`.

## Запуск тестов

1. Установить зависимости:

   ```bash
   pip install pytest requests
   ```

2. Открыть терминал в папке проекта и выполнить команду:

   ```bash
   pytest -v
   ```
